PREVISUALIZAR EN TU ORDENADOR
Abre index.html en Chrome/Safari/Firefox.

PUBLICAR GRATIS
1) Netlify: arrastra la carpeta fated_visuals_site al panel de despliegue manual.
2) GitHub Pages: crea un repositorio, sube estos archivos y activa Pages desde Settings > Pages.
3) Cloudflare Pages: conecta un repositorio de GitHub con estos archivos.
